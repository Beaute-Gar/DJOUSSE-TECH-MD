Comment ça marche :

  1. Entrez votre numéro WhatsApp avec l'indicatif

  3. Un code à 6 chiffres apparaît
  4. Ouvrez WhatsApp → Appareils liés
  5. Cliquez "Connecter un appareil"
  6. Choisissez "Connecter avec numéro de téléphone"
  7. Entrez le code affiché ici
  8. Le bot se connecte et génère votre SESSION_ID
