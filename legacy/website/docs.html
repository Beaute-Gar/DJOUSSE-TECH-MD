Documentation

Construire avec DJOUSSE TECH

La documentation de référence pour comprendre le produit, connecter WhatsApp et publier des données fiables.

DémarrageArchitectureSécuritéContrats API

01 · Guide de démarrage

De l’espace utilisateur à la session

  1. Créer un compte. L’inscription crée un profil isolé dans Supabase.
  2. Créer un bot. Le bot appartient à l’utilisateur authentifié et reste protégé par RLS.
  3. Connecter WhatsApp. Le service de pairing doit fournir un QR ou un code réel ; l’interface ne génère pas de valeur locale.
  4. Observer l’état. Les statuts attendus sont attente, connexion, connecté, déconnecté et erreur.
  5. Utiliser les commandes. Le catalogue doit être découvert depuis le backend, jamais recopié en dur sans source.

02 · Architecture

WhatsApp transporte, DJOUSSE TECH orchestre

Le site actuel est une application HTML, CSS et JavaScript côté client, avec Supabase pour l’authentification, les données et la sécurité par ligne. AINORIA représente la couche intelligente destinée à comprendre le contexte, raisonner et appeler des outils autorisés.

Flux recommandéWhatsApp → service de session → DJOUSSE TECH → AINORIA → commande / action → journal

03 · Sécurité

Isolation et vérité des états

Les identifiants Supabase publics sont utilisables côté client ; aucune clé secrète ne doit y être placée. Les accès aux profils, bots, sessions, logs et statistiques doivent rester conditionnés à auth.uid(). Les rôles administrateur doivent être modifiables uniquement par une opération serveur protégée.

04 · Contrats API

Publier des données vérifiables

Les futures intégrations peuvent utiliser les contrats suivants. Une réponse absente ou en erreur doit produire un état « Donnée indisponible », jamais une valeur de démonstration.

GET /api/commands
{
  "commands": [{
    "name": "ping",
    "syntax": ".ping",
    "description": "…",
    "category": "Général",
    "permissions": ["user"],
    "status": "active"
  }]
}

GET /api/sessions/:botId/status
{ "status": "waiting|connecting|connected|disconnected|error", "qr": null, "pairingCode": null }
