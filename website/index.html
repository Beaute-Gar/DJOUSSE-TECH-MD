Connexion

Deux façons de brancher WhatsApp

Aucune compte WhatsApp Business requis — Baileys (multi-appareils) uniquement.

1 QR Code

  1. Lancez le bot : npm start
  2. Choisissez 1 — QR Code
  3. Sur le téléphone : WhatsApp → Appareils liés → Connecter un appareil
  4. Scannez le QR affiché dans la console
  5. La session est sauvegardée dans session/ : les prochains démarrages se reconnectent seuls

2 Pairing Code

  1. Lancez le bot : npm start
  2. Choisissez 2 — Pairing Code puis le numéro (ex. 2376…)
  3. Notez le code à 8 chiffres affiché (valable 60 s)
  4. Sur le téléphone : WhatsApp → Appareils liés → Connecter un appareil → Lier avec un numéro
  5. Saisissez le code — c'est terminé

🌐 Console en ligne (Vigil)

La console Vigil affiche le statut du bot en direct, le QR, le code de pairing et son journal — et peut lui envoyer des commandes à distance. Tout y est relayé en temps réel depuis la machine qui exécute le bot.

Installation

Trois commandes, et c'est parti

# 1. récupérer le code
$ git clone https://github.com/Beaute-Gar/DJOUSSE-TECH-MD.git
$ cd DJOUSSE-TECH-MD

# 2. installer les dépendances (Baileys 6.7.24 épinglé)
$ npm install

# 3. configurer puis démarrer (audit automatique avant lancement)
$ cp .env.example .env   # → OWNER_NUMBER, PREFIX, etc.
$ npm start
