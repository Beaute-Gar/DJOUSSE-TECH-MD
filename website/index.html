Lier un numéro WhatsApp

Entre un numéro avec son indicatif pays, chiffres seulement — le backend du bot génère le code de jumelage.

— — — — — — — —

Configure d'abord le serveur du bot (voir plus bas) ou lance le bot en local.

  • 1Ouvre WhatsApp sur ton téléphone
  • 2Va dans Réglages → Appareils liés → Lier un appareil
  • 3Touche Lier avec le numéro de téléphone
  • 4Saisis le code affiché ci-dessus
⚙ Serveur du bot (API de jumelage)

URL publique du bot avec PAIRING_API=on (ex. https://mon-bot.example.com). Vide = même origine que ce site.

Pas de serveur ? Mode console

Le bot fonctionne aussi entièrement en local — le code s'affiche dans son terminal.

  • 1Lance le bot sur son hébergement (npm start ou le service détaché)
  • 2Le code d'appairage de 8 caractères s'affiche aussitôt — il se régénère tout seul
  • 3WhatsApp → Appareils liés → Lier un appareil, puis saisis le code
  • ✓La console affiche ✅ CONNECTÉ : le bot reste en ligne 24 h/24

Application mobile (APK)

Ce site est une PWA installable : le bouton « Installer l'app » en haut (ou Chrome → Ajouter à l'écran d'accueil) l'installe comme une vraie application.

  • 1Ouvre ce site depuis Chrome Android (le HTTPS est obligatoire)
  • 2Appuie sur Installer l'app — icône verte DJOUSSE sur ton écran
  • 3Pour un APK signé (Play Store) : passe l'URL du site sur pwabuilder.com → paquet Android (TWA) généré en un clic
