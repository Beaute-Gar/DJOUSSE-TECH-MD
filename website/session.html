Comment obtenir votre Session ID :

  1. Entrez votre numéro WhatsApp avec l'indicatif pays
  2. Cliquez sur "Générer le Code"
  3. Un code à 8 caractères apparaît
  4. Ouvrez WhatsApp → Appareils liés → Connecter un appareil
  5. Choisissez "Connecter avec numéro de téléphone"
  6. Entrez le code affiché
  7. Le bot se connecte automatiquement !

Alternative : Utilisez la commande .pair directement dans le bot WhatsApp pour obtenir un code.
