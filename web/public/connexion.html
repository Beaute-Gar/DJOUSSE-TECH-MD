Associer un numéro au bot.

Demande un code, puis saisis-le dans les paramètres WhatsApp de l’appareil à connecter. Le code sert uniquement à associer ta propre session.

Obtenir un code de jumelage

Entre l’indicatif du pays et ton numéro. Le site ne sauvegarde pas le numéro dans le navigateur.

Entre uniquement des chiffres; le total après indicatif doit compter entre 8 et 15 chiffres.

•••• ••••
Durée de validité : 60 secondes — demande un nouveau code s'il a expiré.
Garde ce code privé.N’envoie jamais ton code à quelqu’un et ne le publie pas dans un groupe.
Trois étapes

Terminer le jumelage dans WhatsApp.

  1. Saisis ton numéro

    Choisis l’indicatif, puis entre les chiffres de ton numéro.

  2. Reçois le code à huit caractères

    Le code s’affiche ici si le worker WhatsApp est en ligne et prêt.

  3. Associe l’appareil

    Sur WhatsApp : Appareils connectés → Connecter un appareil → Associer avec un numéro de téléphone, puis saisis le code.

Une session déjà enregistrée sur le bot ne peut pas être remplacée depuis ce formulaire (HTTP 409).

Le service est indisponible ?

Le jumelage par formulaire nécessite l’API optionnelle du bot ou les fonctions Vercel configurées avec l’URL du bot. Sinon, le propriétaire peut obtenir le code depuis les logs du worker.
