# 🤖 DJOUSSE-TECH-MD

**DJOUSSE-TECH-MD** est un système d'automatisation et d'assistance conçu pour fonctionner directement dans l'environnement WhatsApp.

Le projet fait partie de l'écosystème **DJOUSSE TECH** et regroupe différents outils dans une architecture modulaire.

L'objectif n'est pas simplement d'accumuler des centaines de commandes.

L'objectif est de proposer une expérience plus claire :

```text
                         ┌───────────────────────┐
                         │    DJOUSSE-TECH-MD    │
                         └───────────┬───────────┘
                                     │
                   ┌─────────────────┼─────────────────┐
                   │                 │                 │
                   ▼                 ▼                 ▼
               🤖 AI             🛠️ TOOLS          🛡️ SECURITY
                   │                 │                 │
                   └─────────────────┼─────────────────┘
                                     │
                                     ▼
                              📱 WHATSAPP
```

---

# ✨ Vision

DJOUSSE TECH cherche à construire une couche intelligente au-dessus de l'expérience de messagerie.

# 🚨 Risques liés aux sessions

Une session WhatsApp permet au programme de fonctionner avec le compte associé.

Si les fichiers d'authentification sont exposés, une personne non autorisée pourrait potentiellement compromettre la session.

### À faire

```text
✅ protéger le serveur
✅ protéger le PC
✅ protéger les sessions
✅ protéger les clés API
✅ limiter les accès
✅ supprimer les sessions inutilisées
```

### À ne jamais faire

```text
❌ envoyer sa session à quelqu'un
❌ publier sa session sur GitHub
❌ envoyer son QR dans un groupe public
❌ publier son code d'appairage
❌ mettre ses secrets dans index.cjs
```
